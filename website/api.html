Developer API

Integrate Bhankas Podcast data into your own applications, websites, or research projects with our simple and powerful JSON interface.

Endpoint Overview

Our data is served as a static JSON file, updated every 5 minutes from our automated YouTube scraper.

GET https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json

Data Schema

The API returns an object containing global metadata and an array of individual video entries.

Response Structure 
{
  "last_updated": "ISO-8601 Timestamp",
  "total_videos": 236,
  "videos": [
    {
      "id": "Video ID String",
      "title": "Episode Title",
      "url": "YouTube URL",
      "thumbnail": "Thumbnail Image URL",
      "description": "Video Description Template",
      "duration": 2513, // Seconds
      "view_count": 149028,
      "upload_date": null
    }
  ]
}

Language Examples

Use the following snippets to get started in your preferred language or environment.

JavaScript (Browser/Node) 
fetch('https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json')
  .then(res => res.json())
  .then(data => console.log(`Loaded ${data.total_videos} episodes`));
Python 
import requests

url = "https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json"
data = requests.get(url).json()
print(f"Latest episode: {data['videos'][0]['title']}")
Java (OkHttp) 
OkHttpClient client = new OkHttpClient();
Request request = new Request.Builder()
    .url("https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json")
    .build();

client.newCall(request).enqueue(new Callback() {
    @Override
    public void onResponse(Call call, Response response) throws IOException {
        String jsonData = response.body().string();
        System.out.println(jsonData);
    }
});
Kotlin (Retrofit/OkHttp) 
val client = OkHttpClient()
val request = Request.Builder()
    .url("https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json")
    .build()

client.newCall(request).enqueue(object : Callback {
    override fun onResponse(call: Call, response: Response) {
        val jsonData = response.body?.string()
        println(jsonData)
    }
})
cURL 
curl -L https://raw.githubusercontent.com/samyak2403/Bhankas-Podcast-API/main/data/videos.json
